## Agent usage

Read docs/references/INDEX.md first, then full docs/references/<doc>.md files.
Use rag_search(query, collection='gls-modern-web') and rag_read_document(rel_path) for retrieval.
Deposit research using rag_scrape_url, rag_add_note, or omniconvert_youtube_to_markdown in this collection.
Refresh with rag_sync_project_binder('gls-modern-web'). Raw originals (under 25 MB) are in raw/.
